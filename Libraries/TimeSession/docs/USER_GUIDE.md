# TimeSession — User Guide

## Description

Trading session detection and time management.

## Installation

1. Copy the `TimeSession/` folder to your MT5 `MQL5/Libraries/` directory
2. Include in your code: `#include "TimeSession.mqh"`
3. Call the functions provided by the library

## API

See the header file `Include/TimeSession.mqh` for the full function list and parameter documentation.

## Notes

- Libraries do not have ML modules — they are pure utility functions
- Libraries are bundled with tools that depend on them
- The Archive/ folder contains the original v0.0.1 release
