# Libraries

Reusable MQL5 libraries providing shared functionality across EAs, indicators, and scripts.

## Tools

| Library | Description | Version |
|---------|-------------|---------|
| MathStats | Statistical math functions (mean, std, skew, kurtosis) | v0.0.1 |
| Notifications | Push, email, and alert notification system | v0.0.1 |
| OrderManager | Order execution, modification, and tracking | v0.0.1 |
| RiskManager | Position sizing, drawdown limits, daily loss caps | v0.0.1 |
| TimeSession | Trading session detection and time management | v0.0.1 |

Libraries do not have ML modules — they provide utility functions used by other tools.
