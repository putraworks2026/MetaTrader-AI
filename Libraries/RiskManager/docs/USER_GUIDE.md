# RiskManager — User Guide

## Description

Position sizing, drawdown limits, daily loss caps.

## Installation

1. Copy the `RiskManager/` folder to your MT5 `MQL5/Libraries/` directory
2. Include in your code: `#include "RiskManager.mqh"`
3. Call the functions provided by the library

## API

See the header file `Include/RiskManager.mqh` for the full function list and parameter documentation.

## Notes

- Libraries do not have ML modules — they are pure utility functions
- Libraries are bundled with tools that depend on them
- The Archive/ folder contains the original v0.0.1 release
