# Libraries — Trader Demand Ranking

Ranked by developer demand, reusability, and what MQL5 programmers actively need.

| Rank | Library | Why Developers Need It | Price Range |
|------|---------|----------------------|------------|
| 1 | **Risk Management** | Lot sizing, drawdown limits, daily loss caps — every EA needs this | $15–$50 |
| 2 | **Order Management** | Send, modify, close, partial close — wraps CTrade with safety checks | $15–$40 |
| 3 | **Notification (Alerts)** | Push, email, sound, on-chart alerts — universal requirement | $10–$30 |
| 4 | **Math & Statistics** | ATR, stdev, correlation, z-score — avoids reinventing the wheel | $10–$25 |
| 5 | **Time & Session** | Session detection, timezone conversion, market hours — every EA checks time | $10–$25 |
| 6 | **Indicator Buffer** | Simplifies multi-buffer indicator code — saves hours of boilerplate | $10–$20 |
| 7 | **Price Action** | Candlestick patterns, swing detection, engulfing detection — reusable PA logic | $15–$35 |
| 8 | **Logger & Debug** | Structured logging, file output, verbosity levels — essential for development | $5–$15 |
| 9 | **Trailing Stop Engine** | Multiple trailing algorithms (ATR, fixed, step, breakeven) — plug-and-play | $10–$25 |
| 10 | **Trade Journal** | Records trades to file/DB with metadata — analytics + accountability | $10–$30 |

---

## Buying Signals

- **Tier 1 (Rank 1–3):** Risk Management, Order Management, Notifications — foundational. Every serious EA project needs all three.
- **Tier 2 (Rank 4–6):** Math, Time/Session, Buffer — mid-tier but widely reused across projects.
- **Tier 3 (Rank 7–10):** Price Action, Logger, Trailing, Journal — specialized but saves significant dev time.
